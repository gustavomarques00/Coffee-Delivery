# Coffee Delivery ☕

Coffee Delivery is a frontend application built with **React, TypeScript and Vite**, simulating a complete coffee ordering experience with product selection, cart management, checkout form validation and order confirmation.

This project demonstrates practical frontend engineering skills such as component-based UI, state management, form handling, routing, validation and responsive interface development.

🌍 **Live demo:** https://coffee-delivery-project.netlify.app

---

## 🎯 Project Overview

The application represents a coffee delivery flow where users can browse products, add items to the cart, update quantities, fill delivery information and complete an order.

It was built as a portfolio project focused on frontend architecture, user experience and clean implementation using modern React patterns.

---

## ✨ Features

- Coffee product listing
- Add products to cart
- Increase and decrease item quantities
- Remove items from cart
- Checkout page with delivery form
- Form validation with Zod and React Hook Form
- Order confirmation flow
- Route navigation with React Router
- Styled UI using Styled Components
- Responsive layout
- Typed implementation with TypeScript

## 🧱 Architecture Highlights

The project is organized around reusable components, typed data structures and clear separation between pages, form logic and cart state.

```text
src/
├── components/      # Reusable UI components
├── pages/           # Application pages
├── contexts/        # Shared state and cart logic
├── reducers/        # Cart state transitions
├── assets/          # Static assets
└── styles/          # Global styles and theme
```

---

## 🧠 Technical Highlights

- Component-driven UI with React
- Cart state management with Context API and reducers
- Immutable state updates with Immer
- Form validation using Zod schemas
- Strong typing with TypeScript
- Client-side routing with React Router
- CSS-in-JS styling with Styled Components
- Production build with Vite

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/gustavomarques00/Coffee-Delivery.git
```

Access the project folder:

```bash
cd Coffee-Delivery
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
